# Luau
tools and libraries I made for Roblox development.

## Tools

### I2B64
I2B64 (Image to Base64) is a python tool that converts images into a custom base64 and using luau allows you to recreate that image in Roblox using EditableImages

[Github](https://github.com/solal0/I2B64) [Latest](https://github.com/solal0/I2B64/releases/latest)

### Utils
Utils is a ModuleScript containing a bunch of usefull functions. As of now it only contains I2B64 and a base64 encoder/decoder but i'll add more over time.

[Latest](https://raw.githubusercontent.com/solal0/Luau/refs/heads/main/Tools/Utils.luau)

## Libraries
